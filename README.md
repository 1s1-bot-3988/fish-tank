# 水族箱 · 3D

浏览器里跑的一个 3D 水族箱：程序化生成的水草、底砂、沉木和石头，一群会游的红绿灯鱼，鼠标可以绕着看。

## 运行

双击 `tank.html` 就行。**不需要服务器，也不需要联网** —— three.js 已经放在 `lib/` 里，用本地文件加载。

## 操作

- 鼠标左键拖动：旋转视角
- 滚轮：缩放
- 底部工具栏：
  - **视角**：切换三组预设机位
  - **造景**：一键隐藏 / 显示水草、沉木、石头、底砂（只留缸和鱼）
  - **重置**：回到初始视角
  - **性能**：显示 FPS / draw call / 三角形数
  - 藻类 / 生物 / 环境 / 设置：占位，还没接

## 做了什么

- **玻璃缸**：五面玻璃 + 缸底边框 + 边缘高光
- **底砂**：程序生成的砂床，中间隆起，前缘能看到砂层厚度
- **水草**：约 9000 根地毯草（每根朝向、高度、深浅随机）+ 四簇长叶草
- **造景**：几段弯曲的沉木、四块石头
- **鱼**：34 条红绿灯鱼，有眼睛和摆动的尾巴，绕着自己的轨道游
- **光**：顶部主光 + 缸内点光 + 冷暖补光，砂面有焦散光斑
- **水面**：轻微起伏的波纹
